Educator & Facilitator Toolkit

Facilitator Support: How to link your training session to the Learning Hub — Guidance for Trainers, Educators & Line Managers to facilitate and record sessions.

1
Request the Form

Request the form from your Backbone / Care Groups LHD representative.

2
Complete & Return

Complete the form (example shown above) and email to your LHD representative.

3
Session Published

Your session is created on ESR, displayed on the Learning Hub and added to the calendar.

Tips for completing this form
  • Course name/topic: Write the main name of the course. This is the overall "group name". Example: Poverty Proofing, Autism
  • Class title: Write the full title of the class. Example: "Poverty Proofing: Children's Care Group only", "Autism: Beginners guide to Autism"
  • Class date: Ensure the date matches one of the Learning Half Day dates.
  • Class time: Ensure the time matches a Learning Half Day time.
  • Duration: Write how long the lesson will last and add the times.
Important Submission Guidance
  • Course Availability: If the course is already on ESR (mark 'YES' in Column 3), you only need to complete class delivery columns. If 'NO', please complete all Blue columns so the course can be set up.
  • Submission: Once completed, please email the form to your Backbone / Care Groups LHD representative.
  • Post Session: Complete the orange columns after the Learning Half Day to record attendance and DNAs.
