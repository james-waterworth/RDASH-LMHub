How to complete your class submission

Expand each field below to see exactly what to enter, with examples. Getting these details right first time means we can add your class to the Learning Half Day programme without coming back to you for more information.

Enter the broad subject your class sits under. This acts as the overall “group name” in the programme, and several related classes can share the same course name, so keep it short and general – one or two words is usually enough.

Examples: Poverty Proofing, Autism

Don’t include the audience, level or date here – those details belong in the class title.

Enter the full title of your class exactly as it should appear in the Learning Half Day programme. This is what learners will see when choosing sessions, so make it clear and specific – include the audience or level where relevant. If you’re running more than one class under the same course name, give each class a different title.

Examples: Poverty Proofing: Children’s Care Group only, Autism: A beginner’s guide to autism

Enter the Learning Half Day date on which your class will run. Classes can only take place on published Learning Half Day dates, so check the current schedule before completing this field.

Submissions with a date that doesn’t match a scheduled Learning Half Day may be returned for correction, which could delay your class being added to the programme.

Enter the start time of your class using the 24-hour clock (for example, 09:30 or 13:15). Your class must start and finish within one of the published Learning Half Day session times – check the schedule before completing this field.

Classes scheduled outside these times may need to be rearranged before they can be added to the programme.

Tell us how long your class will last, giving both the total duration and the start and finish times. For example: 2 hours, 10:00–12:00 or 90 minutes, 13:30–15:00.

This helps learners see at a glance how long your session runs, and lets us confirm your class fits within the half-day session.

Still unsure about any of these fields? Contact the Learning Half Day team before submitting and we’ll help you get it right first time.

Important Submission Guidance
  • Course Availability: If the course is already on ESR (mark 'YES' in Column 3), you only need to complete class delivery columns. If 'NO', please complete all Blue columns so the course can be set up.
  • Submission: Once completed, please email the form to your Backbone / Care Groups LHD representative.
  • Post Session: Complete the orange columns after the Learning Half Day to record attendance and DNAs.
